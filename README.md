### 🏃 Marathon Bib Expo

A full-stack event management platform for marathon organizers covering:

* 🎫 Bib distribution
* 👥 Participant management
* 📦 Inventory management
* 🎁 Goodie distribution
* 📊 Event reporting
* 📱 SMS & WhatsApp campaigns
* 🔔 Notifications
* ☁️ AWS-based infrastructure
* 🤖 AI-assisted operations

**Backend:** Java, Spring Boot, Spring JPA, Spring Security
**Frontend:** Angular, TypeScript, PrimeNG
**Databases:** MySQL, DynamoDB
**Cloud:** AWS
**Architecture:** Modular Monolith / REST APIs
